# avr-servo
Управление сервоприводом на ATmega328P: потенциометр, команды с терминала, плавный поворот.
Написано на регистрах, без библиотек Arduino. Проверено в Proteus.
## Что делает программа:
1. Управляет сервоприводом, поворачивая его на определённый угол в зависимости от режима
   - Первый режим: управление осуществляется при помощи потенциометра. При изменении положения ручки потенциометра, изменяется
     положение вала сервопривода. Погрешность 1 градус, так как работа ведётся с целыми числами без округления
   - Второй режим: пользователь вводит команду вида aNN/a-NN, где N - желаемый угол, сервопривод меняет положение. Команда "p"
     переключает обратно в режим потенциометра
2. Сервопривод управляется ШИМ-сигналом
3. Считываются значения из АЦП, UART, переводится в угол поворота вала и в зависимости от режима передаются на порт
4. Через UART так же выводится результат формата "target = -90  now = 29" раз в 0.5 с
5. Ввод в терминал команды неправильного формата (в том числе в виде пустой строки) игнорируется
6. Вал доворачивается до заданного угла плавно, актуальное положение выводится в терминал как "now"
## Схема
- PB1 (OC1A) — сигнал сервопривода. Верхний вывод - сигнал с PB1, средний - +5 В, нижний - земля. Свойство
   сервопривода в Proteus Rotational Speed = 1000
- A(PB1) — осциллограф
- PC0 (ADC0) — потенциометр
- PD0/PD1 — Virtual Terminal, 9600 бод
     - TXD чипа (PD1) - RXD терминала
     - RXD чипа (PD0) - TXD терминала
- AVCC (18) +5 В
- ATmega328P, 16 МГц, CKSEL Fuses (1111)
## Команды
'aNN'/'a-NN' - задать целевой угол сервопривода
'p' - переключение в режим потенциометра
## Как устроено
1. Timer1  используется для управления ШИМ - сигналом. Неинвертирующий ШИМ, режим 14 Fast PWM. Период 20мс, начальное положение вала 0 градусов.
   Так же используется в прерывании каждые 20 мс. Поднимается флаг, сообщающий о том, что можно изменить положение сервопривода. Это используется для плавного
   поворота вала сервопривода до целевого значения, он поворачивается на 1 градус каждые 20 мс.
2. Timer2 используется для вывода значений в терминал. В прерывании каждые 0.5с поднимается флаг, сообщающий о том, что можно выводить результат работы в терминал.
   Изначально работает в 16 мс, 0.5с достигается при помощи счётчика в прерывании. Режим СТС, делитель 1024.
3. АЦП используется для чтения значений с потенциометра, которые преобразуются далее в целевой угол. Делитель частоты 128, опорное напряжение +5В
4. UART используется для отправки значений в терминал и считывания команд. При чтении посимвольно разбивает пришедшую строку, занося в массив.
5. После массив разбирается и проверяется на корректность полученной строки: содержит ли цифры, содержит ли знак минус, сколько именно цифр, собирает их в одно число,
   проверяет на соответствие границам (−90 до 90). Работа только с целыми градусами. При соответствии формату формируется целевой угол поворота вала сервопривода.
6. Пока в консоль не введена команда верного формата сервопривод работает от потенциометра. Как только вводится верная команда, целевой угол берётся только из консоли.
   При вводе команды 'p' в терминал сервопривод снова начинает работать от потенциометра.
## Шаги проекта
| Папка | Что добавлено |
|---|---|
| step1 | ШИМ на OC1A, Fast PWM 8 бит|
| step2 | сервопривод в Proteus|
| step3 | автоматическое переключение положений сервопривода|
| step4 | потенциометр управляет сервоприводом|
| step5 | вывод угла со знаком в терминал|
| step6 | команды aNN и p с терминала|
| step7 | плавный поворот к целевому углу|
## Как запустить
1. Открыть проект в Arduino IDE. Нажать на галочку слева сверху, чтобы проверить, что всё компилируется.
   После удачной компиляции выполнить следующие действия: Нажать "скетч" - "экспорт бинарного файла"
2. Схема Proteus должна находиться в одной папке с файлом кода. Запустить Proteus обязательно от имени администратора, иначе не будут работать библиотеки.
   После появления схемы два раза щёлкнуть по микроконтроллеру и нажать на обзор "Program file", если до этого был экспортирован файл кода, то должно быть
   два hex файла. Стоит выбрать файл без "with_bootloader" в названии. После загрузки кода настроить все характеристики что указаны выше (там всё уже должно
   быть настроено, но проверить стоит). Запустить симуляцию
